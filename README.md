# Poppy Vision

基于深度学习的罂粟图像分类识别项目。

## 项目功能

本项目使用计算机视觉方法，对植物图片进行二分类识别：

- poppy（罂粟）
- non_poppy（非罂粟）

模型可以输入单张图片，并输出预测类别和置信度。

---

- Python >= 3.11
- PyTorch
- Ultralytics YOLO Classification
